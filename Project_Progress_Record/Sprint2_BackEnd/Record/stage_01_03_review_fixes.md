## 1. 核心修改

| 问题 | 修正结果 |
| --- | --- |
| R1：管理命令事务与幂等 | 授予、撤销管理员权限及初始化密码均锁定目标账号，账号变更与审计同事务提交；审计失败整体回滚，并发重复操作仅记录真实变更。 |
| R2：密码初始化边界 | 仅允许无可用密码的账号初始化，锁内再次检查状态；与注册共用新密码策略，拒绝超长密码及覆盖已有密码；支持终端无回显输入和标准输入管道。 |
| R3：姓名相似密码 | 显式配置邮箱、姓名属性的相似度验证，注册和初始化统一执行 8～128 字符及 Django 密码策略。 |
| R4：失败限流 | 字段校验、JSON 解析及业务认证失败均进入相应计数路径；有效邮箱与 IP 各计一次，无效邮箱或 JSON 解析失败仅计 IP；保持 CSRF 优先验证、操作类型隔离、成功清零及窗口恢复。 |
| R5：公告链接 | 统一创建、编辑的 URL 校验；解析异常、非法主机/端口及不允许的协议返回 400，不产生业务副作用。 |
| R6：文档一致性 | API 统一为 39 个已实现方法/路径（含开发登录）及 2 个 SSO 预留，补全公开入口；订正验收用例、事项分类、锁定范围及兼容字段说明，交接仅保留团队仓库信息。 |

代码沿用账号、公告与管理命令分层；新增 `backend/apps/accounts/passwords.py` 统一新密码校验。未新增业务数据表或修改历史迁移。

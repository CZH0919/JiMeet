# Sprint 3 后端阶段 5　数据清理与账号注销

2026-11-23，czh 完成[开发计划阶段 5](../Plan/sprint3_backend_plan.md)。工作分支为 `backend-sprint3`，开发基线为 `88f64c6`，实现提交为 `7757e37`。

## 交付内容

| 范围 | 完成情况 |
| --- | --- |
| 申请留存 | 自招聘首次关闭、满员或删除的最早时间起保留 180 天。到期即停止展示申请明细、关联通知和简历下载。清理时保留五种申请状态的匿名数量，移除明细、历史和关联记录。重复执行及处理已有汇总记录均不重复计数。 |
| 简历删除 | 文件删除任务与数据库变更一同提交。事务回滚时保留原文件，提交后执行删除，失败任务可重试。 |
| 本人注销 | `DELETE /me` 校验登录、CSRF 和本人明确确认。注销后全部设备会话及旧邮箱验证资格失效，清除身份资料、简历和本人发出的聊天正文。原邮箱重新验证后可注册独立普通账号。 |
| 业务结果与审计 | 注销发布者的在招招聘停止接收申请，相关申请人收到通知。注销申请人的处理中申请按撤回计数，已接受申请保留匿名名额，满员招聘保持关闭。审计去除可识别的操作者关联，按至少一年留存要求保留操作时身份、对象、动作、原因及时间。 |

## 验证结果

- 服务器 PostgreSQL 隔离测试库全量回归 **398/398** 通过，其中针对性回归 **125/125**。覆盖 180 天临界点、历史匿名统计、清理重跑、文件删除失败重试、注销与投递或清理并发，以及同邮箱重新注册后的权限隔离。
- 另用三个独立会话通过真实 HTTP 验证双设备注销、申请结果、聊天正文清除和公开发布者匿名展示。Django 系统检查、迁移差异检查通过，五项新增迁移已在开发环境应用。
- 服务端路由与[接口正文](../../../backend/design_file/api.md)一致。开启与关闭开发登录时分别有 54 和 53 个可用方法与路径组合，另有 2 个 SSO 预留接口。

## 对接与运行

- 前端按[本人注销](../../../backend/design_file/api.md#49-delete-me本人注销)展示影响并确认，收到成功响应后清空本人缓存、返回登录页。公开发布者或聊天对方的编号为空时，隐藏联系入口。
- [时间与删除边界](../../../backend/design_file/api.md#91-时间与删除边界)列明到期行为。`python manage.py run_purge_applications` 执行匿名汇总并重试简历删除，仍有文件待重试时返回非零退出码。生产定时调度属于阶段 6。

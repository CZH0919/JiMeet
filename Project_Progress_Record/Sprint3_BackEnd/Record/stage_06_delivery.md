## 运行支持

| 项目 | 交付内容 |
| --- | --- |
| 启动与探活 | 提供非 root 生产镜像配置、Gunicorn 启动命令和 Nginx 同源 HTTPS 代理。专用 Unix 套接字接收代理请求，使用安全 Cookie 和代理覆写的客户端地址。健康接口检查数据库，容器探针读取同一接口。 |
| 任务与告警 | 提供招聘状态同步、申请及简历清理、聊天清理的调度配置。相同任务互斥，失败以非零状态退出。验证码监控检查 SMTP 连接、认证和近期投递失败比例；失败写系统告警，可推送至独立 HTTPS 接收端。 |
| 备份与迁移 | 每日备份 PostgreSQL，至少保留 30 天，校验通过后才能恢复至新库。本阶段新增 `accounts.0007_mail_delivery_result`，记录 SMTP 是否受理验证码；旧流水保留未知结果。升级时由 `migrate` 按依赖应用全部未执行的迁移。 |
| 接口与资料 | 已核对正常路由、关闭方法、权限和错误响应。启用与关闭开发登录时分别有 54、53 个可用方法与路径组合，另有两个 SSO 入口返回 501。清理了正式代码和接口正文中的迭代标注、过时的聊天说明，以及验收用例中的旧阶段编号。 |

## 服务器验证

| 范围 | 结果 |
| --- | --- |
| 共享回归 | PostgreSQL 隔离测试库 **403/403** 通过，其中账号、健康检查和招聘调度专项 **97/97**。Django 系统检查通过，模型无迁移漂移。 |
| 跨模块 HTTP | 三个独立会话走通投稿、领取、原文发布、招聘投递、简历权限、接受至满员、通知、聊天回执与注销。管理员越权读取简历或私聊返回 404，公告编辑返回 405。核对了本人资料、招聘、申请和消息响应与文档示例的字段。 |
| HTTPS 与故障 | 以生产设置运行 Nginx 和 Gunicorn，通过隔离 TLS 邮件服务完成验证码注册。验证 HTTP 跳转、安全 Cookie、CSRF 和来源 IP。SMTP 认证失败或失败率超限触发告警，独立 HTTPS 接收端实际收到告警；数据库中断时健康接口返回 503。 |
| 迁移与恢复 | 在独立临时实例从空库应用迁移，验证已有投递流水升级后结果为 NULL。备份恢复至新库后核对迁移、账号及投递记录；已存在目标库和损坏归档均被拒绝。通过构造 29 天、31 天副本验证保留与轮换。 |

## 上线验收边界

服务器没有可用的 Docker 引擎。已按 Dockerfile 的文件布局在干净环境安装生产依赖、检查默认启动命令，并以非特权账号实际运行同一应用和代理。镜像构建及容器启动、正式域名证书、校内 SMTP 投递、值班告警接收和备份异地留存须在目标部署环境核验。生产设置的 HSTS 仅作用于本站，子域覆盖及预加载由域名管理方决定。

前端负责页面适配。完整浏览器交互、300 人在线性能、高峰可用率和连续 30 天备份留存由部署后的测试及运维记录验证。功能边界与验收步骤见[需求验收用例](../../../file/tasks/需求验收测试用例.md)。

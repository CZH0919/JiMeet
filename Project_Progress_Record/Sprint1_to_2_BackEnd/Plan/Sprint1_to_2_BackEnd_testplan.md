## 1. 执行阶段

| 阶段 | 工作内容 | 产出 |
| --- | --- | --- |
| 1. 运行检查 | 完成系统检查、迁移一致性检查及服务启动确认。 | 运行检查结论。 |
| 2. 共享回归 | 执行 `backend/tests/` 全量测试，核对通过、失败和跳过项，覆盖数据库事务及文件处理行为。 | 回归结果与问题清单。 |
| 3. 接口与边界验证 | 依据 `backend/design_file/api.md` 和下表验证真实 HTTP 主流程，核对响应及数据库、私有文件副作用。 | 接口覆盖与边界验证结果。 |
| 4. 问题复测与记录 | 区分适配问题、功能缺陷和契约差异；按确认范围修复并复测，明确剩余限制。 | `Project_Progress_Record/Sprint1_to_2_BackEnd/Record/` 中的测试记录。 |

共享回归入口：配置独立测试数据库后，在 `backend/` 执行 `python manage.py test tests --keepdb --noinput --settings=config.settings.test`。

## 2. 功能与边界矩阵

| 范围 | 主要验证内容 |
| --- | --- |
| 公共响应与身份 | 健康检查、响应信封、请求标识、错误码、分页与参数拒绝；CSRF 获取、开发登录开关与令牌轮换、会话退出、资料修改、隐私确认幂等；SSO 返回约定的 501。 |
| 招募 | 发布、标签关联、详情、搜索/筛选/分页、本人列表、修改、手动关闭与软删除；人数和时间校验、学生/教师发布规则、越权及管理员删除理由；满员与已删除状态的可见性。 |
| 申请入口 | multipart 投递、禁止向本人发布的招募投递、未确认隐私拒绝、重复投递、撤回后重投；双方列表/详情、状态筛选、字段裁剪及操作权限输出。 |
| 申请处理 | 修改说明/替换简历、撤回、接受/拒绝、暂留/取消暂留；已阅确认版本匹配、过期确认保留修改标记；重复操作的幂等或冲突响应、终态限制。 |
| 私有文件与权限 | 非空 PDF/DOC/DOCX、10 MiB 边界、伪造内容/大小、文件名与路径逃逸；申请人/发布者合法下载、无关用户及管理员越权拒绝；撤回/失效/留存到期禁读、缺失文件处理及缓存响应头。 |
| 通知与审计 | 通知列表、未读数、单条/全部已读及本人范围；招募修改/删除仅通知 processing/accepted 申请人，管理员删除另通知发布者；业务审计、通知和待发邮件记录与事务结果一致。 |
| 时间与留存 | 截止即停止投递、关闭后七天自动拒绝、满员优先、软删除失效；180 天留存边界及分页前过滤；查询展示状态与写操作/`run_sync_recruitments` 补执行一致，重复补执行不产生重复副作用。 |
| 一致性与失败处理 | 重复申请、竞争最后名额及接受/撤回等并发冲突；人数上限、唯一约束、招募到申请的锁顺序；事务失败无部分业务记录，失败上传清理新文件、替换成功后清理旧文件；提交后邮件占位派发异常不回滚已提交业务。 |

HTTP 主流程：开发身份登录与隐私确认 → 发布招募 → 另一身份投递 → 查询与修改 → 发布者已阅/暂留/处理 → 通知已读；另行覆盖撤回重投、关闭、满员及删除。31 个已实现方法/路径分别验证成功场景及适用的失败、权限场景，另核对 2 个 SSO 占位响应。

本轮验证范围不包含正式认证、真实邮件投递、前端页面、聊天/推荐、软删除恢复、留存物理清理或生产部署验收；初版性能指标不作为硬性门槛。完成时各失败、跳过和契约偏差须有明确结论，权限、私有文件、状态/人数及事务一致性不存在未解决的阻断问题。

# 需求验收测试用例

账号、公告投稿、通知、招聘及站内聊天用例按[需求 3.1](软件需求规格说明3.1.md)和[Sprint 3 后端计划](../../Project_Progress_Record/Sprint3_BackEnd/Plan/sprint3_backend_plan.md)维护。接口字段与错误码见[接口正文](../../backend/design_file/api.md)。测试使用合成账号及虚构简历。

## FR-01 邮箱账号注册与登录

| 编号 | 前置 | 步骤 | 预期结果 |
| --- | --- | --- | --- |
| AT-01-01 | 未注册的同济邮箱 | 同会话获取 CSRF、发码并验码，提交邮箱、两次相同密码、姓名和身份 | 验码后尚未建号。注册返回 201、本人资料及普通用户会话，隐私同意默认为否 |
| AT-01-02 | 无账号 | 分别以 `a@tongji.edu.cn.evil.com`、`a@evil-tongji.edu.cn` 注册 | 400 `VALIDATION_ERROR`，不建账号 |
| AT-01-03 | 已有账号 | 对同一邮箱的大小写变体发码，分别在核验前后提交注册 | 正常投递。核验前不提示账号状态；核验成功仅提示已注册，建号资格有效秒数为 0。已有账号保持原状 |
| AT-01-04 | 同一邮箱有有效核验资格 | 并发完成注册，包括不同已核验会话 | 仅创建一个账号，失败请求返回 400 |
| AT-01-05 | 已核验的未注册邮箱 | 分别提交 7/129 位密码、纯数字密码、常见弱密码、与邮箱或姓名相似的密码 | 均 400，指出密码不合规，不建账号 |
| AT-01-06 | 无账号 | 注册体中提交 `is_admin=true`、`is_staff=true` 或未知字段 | 400；即使字段被识别也不得授予权限 |
| AT-01-07 | 无 CSRF 凭据 | 匿名提交发码、验码、注册或登录 | 403，拒绝请求 |
| AT-01-08 | 已有账号 | 登录：不存在邮箱；存在但错误密码；不可用密码 | 三种情况均 401 `AUTH_FAILED`，提示一致，不泄露账号是否存在 |
| AT-01-09 | 账号已停用 | 以正确密码登录 | 403 `FORBIDDEN`；会话不建立 |
| AT-01-10 | 已有账号 | 正确邮箱密码登录 | 200 建立会话并轮换 CSRF；`GET /me` 返回本人资料；登出后原会话访问 `/me` 得 401 |
| AT-01-11 | 已取得 CSRF | 注册、登录分别以同一邮箱连续失败 5 次（含字段、密码策略及凭据失败）后再请求 | 各操作第 6 次起 429；每次失败只计一次；邮箱不可解析时仅按 IP 计数，IP 第 21 次起受限；换 IP 不解除邮箱限制，换邮箱不解除 IP 限制；600 秒窗口滑过后恢复 |
| AT-01-12 | 失败次数未达阈值，或限流窗口已恢复 | 以正确密码登录成功后再次失败登录 | 成功清除该邮箱键计数，之后重新累计；限流仍生效时正确密码也返回 429 |
| AT-01-13 | 已有账号 | 登录/注册响应与 `/me` 响应检查 | 不返回密码、密码摘要、`real_id`、`sso_subject` 等内部标识 |
| AT-01-14 | 已核验的新注册账号及历史账号 | 检查核验时间、响应字段及权限 | 新账号记录邮箱核验时间，历史账号留空。姓名、身份标签只用于展示 |
| AT-01-15 | 历史无可用密码账号 | 以受控命令初始化并登录；重复初始化、超长及相似密码、并发初始化 | 合规初始化后可登录；已有密码不被覆盖；无效密码不写入；并发仅一次成功；无公开重置入口，终端输入不回显、管道密码不输出 |
| AT-01-16 | 开发配置 | `ALLOW_DEV_LOGIN` 关闭后调用开发登录 | 404；注册登录主链路不受影响 |
| AT-01-17 | 隔离测试邮箱及会话 | 错码、过期、换邮箱、换会话、重发后用旧码、并发验码 | 返回 400，只有当前有效码在原会话中可成功核验一次 |
| AT-01-18 | 已获得注册资格 | 提交弱密码后更正，再测试资格过期与重放 | 可在有效期内更正，失效或重放均被拒绝 |
| AT-01-19 | 控制时间及发送额度 | 并发发码、冷却未结束、触达邮箱/IP/全局上限、模拟投递失败及乱序完成 | 超额返回 429，投递异常返回 503，失败码不生效，迟到的旧投递不覆盖新码 |
| AT-01-20 | 隔离收件箱、独立回归库 | 通过 HTTP 连续完成发码、验码、注册、查询本人、退出及密码登录 | 建号前无用户记录，成功后会话轮换且只能访问本人的身份 |
| AT-01-21 | 同济邮箱及有效 CSRF | 分别以表单、无效 JSON、非同济邮箱登录，模拟发信失败 | 媒体类型不支持返回 415，字段或 JSON 错误返回 400；成功与错误均禁止缓存。发码故障返回 503，密码登录仍可用 |
| AT-01-22 | 本人在两台设备登录 | 在一端确认注销，另端访问本人接口，再用原邮箱重新注册 | 原会话及旧验证码失效，新账号为普通用户且无旧私有记录 |
| AT-01-23 | 本人同时有招聘、投递和聊天 | 注销后由对方查申请状态、通知与会话 | 关闭未结束招聘，处理中投递撤回，已接受名额保留。本人简历和发出的聊天正文清除 |

## FR-04 简历文件上传与访问

| 编号 | 前置 | 步骤 | 预期结果 |
| --- | --- | --- | --- |
| AT-04-01 | 投递窗口内 | 上传 PDF/DOC/DOCX 简历（各格式、非空、≤10 MiB） | 201 创建申请并保存简历 |
| AT-04-02 | 投递窗口内 | 分别上传 0 字节、>10 MiB、伪造扩展名（如 .pdf 实为文本）、其他格式 | 分别 400 `INVALID_RESUME_FILE`（reason=size/type/signature）或 `VALIDATION_ERROR`；不产生残缺申请、不残留文件 |
| AT-04-03 | 有 processing 申请 | 修改申请替换简历 | 新版覆盖；旧版文件在事务成功后清理；失败路径保留旧版 |
| AT-04-04 | 申请已撤回 | 申请人下载本人简历；发布者下载该简历 | 申请人可下载（文件仍保存）；发布者 403/404 禁读 |
| AT-04-05 | 招聘已删除 | 发布者下载该招聘下全部简历（含 rejected、withdrawn 记录） | 全部禁读；各申请人仍可下载本人保留简历 |
| AT-04-06 | 任意管理员 | 下载他人简历 | 404/403，治理权限不授予简历读取权 |
| AT-04-07 | 无业务关系用户 | 遍历 application id 请求简历 | 全部 404，不泄露存在性 |
| AT-04-08 | 发布者查看申请人简历 | 下载简历 | 写 `resume_view` 审计；响应 `Cache-Control: private, no-store` |
| AT-04-09 | 同一招聘有多个结束时间 | 以最早时间分别检查满 180 天前一瞬及到期当刻，执行并重跑清理 | 明细与简历按时退出，保留五状态统计，文件删除失败可重试 |
| AT-04-10 | 已注销申请人与仍在册申请人属于同一招聘 | 注销与留存清理并发执行 | 已录取名额及匿名数量只统计一次，审计保留事实与操作时角色，身份外键解除 |

## FR-05 招聘信息发布与管理

| 编号 | 前置 | 步骤 | 预期结果 |

| AT-10-06 | 月末、闰年与六个月到期边界 | 对照历史、会话摘要、未读数，重复运行到期清理 | 精确到期同时隐藏，物理删除仅影响到期消息，会话和仍有效消息保留 |
